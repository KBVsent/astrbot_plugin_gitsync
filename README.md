# astrbot_plugin_gitsync

一条指令拉取并热重载所有由 git 管理的 AstrBot 插件。

适合用 `git` 维护私有仓库插件的场景:把「进目录 `git pull` → 回 WebUI 点重载」两步合并成一条聊天指令,无需重启 AstrBot。

## 功能

- 自动发现 `data/plugins/` 下**含 `.git` 目录**的插件(插件市场下载的插件不带 git,自动排除)。
- 拉取更新后热重载,**仅重载真正有更新的插件**(HEAD 未变则跳过)。
- 更新后若 `requirements.txt` 有变化,自动安装缺失依赖再重载。
- 逐插件回执:已是最新 / 已更新并重载 / 失败原因。
- 更新器自身始终排除在自动重载之外,避免自杀式重载。

## 指令(仅管理员)

| 指令 | 说明 |
|------|------|
| `/gitsync` | 列出所有 git 插件(分支 / 短 hash / 是否加载),不拉取 |
| `/gitsync all` | 拉取并重载全部 git 插件(仅重载有更新的) |
| `/gitsync <名字>` | 更新单个插件。模糊 + 忽略大小写:全等优先;唯一命中执行;命中多个只列名单不执行;无命中提示未找到 |

## 配置

| 配置项 | 默认 | 说明 |
|--------|------|------|
| `pull_mode` | `ff-only` | `git pull` 方式:`ff-only`(遇分叉直接失败,最安全)/ `merge` / `rebase` |
| `reinstall_deps` | `true` | 更新后检测到 `requirements.txt` 变化时自动安装缺失依赖 |
| `exclude` | `[]` | 额外跳过的插件目录名(自身已自动排除) |
| `git_timeout` | `120` | 单次 git 操作超时(秒) |

## 说明

- 拉取失败(工作区脏、无 upstream、`ff-only` 遇分叉、超时等)只在回执报错并跳过该插件重载,不影响其余插件。
- 依赖安装失败时不重载,避免半更新。
- 私有仓库需宿主机上的 git 已配置好访问凭证(SSH key 或 `~/.netrc` 等)。
